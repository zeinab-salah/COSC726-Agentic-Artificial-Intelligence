# Grounded technical briefs

COSC726 capstone for **Zeinab Salah**. A Researcher, a Writer, and a Reviewer produce a short brief on a public AI tool. Every sentence must overlap a retrieved snippet, or the run stops as `ESCALATED`. A person releases the brief. The language model does not.

**Marker path (no API key):** clone, run the tests, run the demo, start the service, brief `Aider` in offline mode.

## 1. Requirements

- Python 3.11 or newer (`python --version`)
- Git
- A browser
- No package install. Standard library only.

Live mode is optional. Offline mode is enough for a working run and for the frozen numbers in `REPORT.md`. If you cloned this repository, `week01/` and `week2/` are earlier lab notes and are not part of the marker path.

## 2. Clone and run (offline, no key)

```bash
git clone https://github.com/zeinab-salah/COSC726-Agentic-Artificial-Intelligence.git
cd COSC726-Agentic-Artificial-Intelligence
python -m unittest brief.test_brief brief.test_live baseline.test_baseline behaviour.test_behaviour loop.test_loop
python -m brief.run_demo
python -m brief.service
```

Expected:

- Tests print `OK` (about 80 tests).
- `run_demo` prints `approval 75%  crew grounding 100%  baseline grounding 0%  controls 8/8` and writes `REPORT.md` plus `runs/final_eval.json`.
- The service prints `brief service on http://127.0.0.1:8000`.

Open http://127.0.0.1:8000

1. Choose **Offline corpus**.
2. Topic: `Aider`
3. Click **Run**.
4. Status should be **APPROVED**. The right-hand panel shows the brief. Sources lists four quotes from allow-listed pages.
5. Click **Release**. `released` becomes true. The same action with the same key does not flip it twice.

That is a working run. Stop the server with Ctrl+C.

Windows PowerShell: the same commands, from the cloned folder.

## 3. HTTP check without the page

```bash
curl http://127.0.0.1:8000/health
curl -X POST http://127.0.0.1:8000/v1/runs -H "Content-Type: application/json" -d "{\"topic\": \"Aider\", \"mode\": \"offline\"}"
```

The POST returns `201` with `"status": "APPROVED"` and `"released": false`. Copy `run_id`, then:

```bash
curl -X POST http://127.0.0.1:8000/v1/runs/<run_id>/decision -H "Content-Type: application/json" -d "{\"action\": \"approve\", \"idempotency_key\": \"k1\"}"
```

## 5. Live mode (optional)

Live mode searches the web and calls a model. It is **not** required to mark the frozen evaluation.

1. Copy `.env.example` to `.env`. Never commit `.env`.
2. Set `LIVE_PROVIDER` to `gemini`, `ollama`, or `auto`.
3. Gemini: add `GEMINI_API_KEY` from [Google AI Studio](https://aistudio.google.com/apikey), then `python -m brief.live_check`.
4. Ollama: install from [ollama.com](https://ollama.com/download), `ollama pull qwen2.5:7b`, set `LIVE_PROVIDER=ollama`.
5. Restart `python -m brief.service` and choose Live.

A Gemini daily quota error (HTTP 429) switches that run to Ollama if it is installed, and later runs skip Gemini until the next reset. `python -m brief.live_check --resume-gemini` clears the pause. Search retries a timed-out DuckDuckGo request, then tries the lite page.

## 8. How a run is allowed to stop

1. Search allow-listed pages (cached corpus, or the web in live mode).
2. Drop injected instructions and off-list hosts.
3. Keep a quote only if it appears in the page.
4. Draft only from those quotes (320–480 words).
5. Deterministic citation check. At most one offline rewrite (two in live mode).
6. `APPROVED` or `ESCALATED`. `released` stays false until a person passes the same check again.

The cycle is `for cycle in range(MAX_REVISION_CYCLES + 1)`. There is no `while True`. CrewAI is the role pattern, not the control plane.

## Design notes

The Writer sees evidence rows, not planted prices. Two runs do not share `CrewState`. Trace events are JSON actions and reasons, not a private chain of thought. Section 8 of `REPORT.md` records why CrewAI is not imported.
